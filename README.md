# Preptember: Your First Steps Toward Open Source

Welcome! This is the practice repository for Preptember: Your First Steps Toward Open Source, a 90-minute beginner-friendly workshop for NJIT students who are curious about GitHub, open source, or Hacktoberfest but have little or no prior experience.

This workshop is especially for first-time contributors, students from non-CS backgrounds, and anyone who wants a gentle introduction before trying their first pull request.

## What you'll learn

- What a GitHub repository, issue, and pull request are, and how they fit into an open source workflow.
- How to find and attempt a beginner-friendly open source task.
- How to open a practice pull request and describe the steps you took to contribute.

## How this repo is organized

- docs/cheat-sheet.md - a one-page cheat sheet of GitHub terms and the workshop steps.
- docs/resources.md - follow-up resources for Hacktoberfest and beginner-friendly open source projects.
- submissions/ - where workshop facilitators draft and track the workshop design write-up.
- Issues tab - a few beginner-friendly practice tasks (typo fixes, small doc edits) that attendees can pick up during the workshop.

## Workshop flow

- Welcome and framing: introductions and connecting the workshop to Preptember and Hacktoberfest.
- Concept overview: what repositories, issues, branches, and pull requests are for.
- Guided walkthrough: a live demo of reading an issue through opening a pull request in this repo.
- Shared practice: attendees pick a practice issue and draft a short contribution plan.
- Build time: attendees make a small change (fix a typo, edit a doc) in this repository.
- Pull request review: how to write a clear PR description and respond to feedback.
- Wrap-up and next steps: resources for real beginner-friendly projects and Hacktoberfest.

## Getting started (attendee workflow)

Fork this repository to your account, then clone your fork:

git clone https://github.com/YOUR-USERNAME/preptember-open-source-workshop.git
cd preptember-open-source-workshop

Create a branch for your practice contribution:

git checkout -b my-practice-branch

Make a small change (see the Issues tab for ideas), then commit and push:

git add .
git commit -m "Describe your practice contribution"
git push origin my-practice-branch

Open a pull request back to this repository.

The goal is not perfection - the goal is to experience the open source contribution workflow end to end.


Happy contributing!
