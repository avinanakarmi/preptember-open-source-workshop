# Follow-up Resources

Ready to keep going after the workshop? Here are some next steps.

## Hacktoberfest

- Hacktoberfest official site - https://hacktoberfest.com/
- Hacktoberfest participation rules and how contributions are counted.

## Beginner-friendly projects and issues

- Good First Issue - https://goodfirstissue.dev/
- Up For Grabs - https://up-for-grabs.net/
- GitHub Explore - https://github.com/explore
- Search GitHub for the "good first issue" label on projects you already use or admire.

## Learning more Git and GitHub

- GitHub Docs: Git and GitHub learning resources - https://docs.github.com/get-started
- GitHub Skills (interactive courses) - https://skills.github.com/
- Git basics - https://docs.github.com/get-started/using-git/about-git

## Next steps after this workshop

- Pick one real beginner-friendly issue in a project you care about and read through it carefully.
- Ask questions in the project's discussion board or issue comments before starting.
- Keep practicing the fork, branch, commit, push, pull request workflow until it feels natural.
- Come to the next NJIT open source session to share what you tried and ask for help.
